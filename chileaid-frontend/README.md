# Chile Aid — Frontend

Plataforma web de gestión de donaciones humanitarias en Chile. Construido con Nuxt 4 + Vue 3 + TailwindCSS.

## Requisitos

- Node.js 18+
- npm

## Cómo correr el proyecto

```bash
# 1. Instalar dependencias
npm install

# 2. Levantar el servidor de desarrollo en http://localhost:3000
npm run dev
```

## Otros comandos

```bash
npm run build     # build de producción
npm run preview   # previsualizar el build de producción localmente
npm run generate  # generar sitio estático
```
